Canis is a game engine I have been working on for the last 5 years. It is writen in C++ and uses OpenGL for rendering. The Engine is built around a data oriented model, but also supports having one class per entity.

  • Created systems for input, sprite rendering, 3d rendering, asset management, and application lifecycle.
  • 2D WebGl support with emscripten.
  • Libraries used SDL2, GLEW(OpenGL), GLM, and STB
  • It has been used to creat StopTheSlimes, Shark Bonk, Garden of Doom, Space Miner, and Dual Defenders
