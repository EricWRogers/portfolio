Garden of Doom was made for Global Game Jam 2023. Most the team members had played Vampier Survivor and wanted to make a game like it.

  • Writen in C++ using the Canis Game Engine.
  • Leading up the jam I wrote a sprite animation and scene system.
  • Enimy movement using a modified boid algorithm.
  • Helped with Player, Enimies, and Weapons
  • Added Controller Support to the engine.
  • Added UI sliders to the engine.
