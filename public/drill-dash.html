Inspired by old school arcade shooters, mixed with roguelike elements, Drill Dash is set in a post-apocalyptic world where mech-equipped drillers are launched from railgun platforms into a vast environment full of destructive raiders, haywire robots and mutated locals. This was the first new project we started with our in house library of script, and it improved our prototyping speed.

My Part :

  • Programming team lead for this project.
  • Developed the Localization System.
  • Integrated Steam SDK / Google Admob
  • Added analytics using Unity Analytics and Firebase
  • Tools Used: C#, Unity 3D, Git, VS/VS Code, Admob, Unity Analytic, Firebase
