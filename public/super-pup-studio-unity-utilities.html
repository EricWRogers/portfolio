This set of C# Unity Game Engine Ultilities for faster prototyping. (2022 - Present)

  • A group of manager for Location, Score, and Currency
  • It includes a set of 2D scripts to start making platformer faster.
  • Has tools for quick optimisation example ObjectPool.
  • Helper script useful to most project Timer, Health, Bullet, CountDownText, and Damage Indicator.
  • This has been used to prototype over 20 games.
