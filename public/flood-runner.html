The player plays a robot trying escape the raising water. Run and wall jump to freedom while shooting at turrets in the way. This game was created during LSU Sheveport Game Jam 2019 where the theme was flood. Our team of 6 got 1st place and were awarded $550.

  • Environment Programming
  • Level Building
  • Flood System
  • Effect / Post Processing
  • Tools Used: C#, Unity 3D, Git, VS/VS Code
